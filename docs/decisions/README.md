# Architecture Decision Records (ADRs)

This directory records significant technical and architectural decisions for the **Store Rating Platform**, capturing context, options evaluated, decisions made, and their consequences.

---

## ADR Format

Each ADR must follow this standard template:

```markdown
# ADR-<NUMBER>: <TITLE>

## Status

[Proposed | Accepted | Superseded | Deprecated]

## Context

What is the problem or architectural need being addressed? What constraints exist?

## Decision

What is the chosen approach or solution?

## Alternatives Considered

- Option A: (Pros / Cons / Reason rejected)
- Option B: (Pros / Cons / Reason rejected)

## Consequences

- Positive impacts
- Negative impacts / Tradeoffs
- Risks and mitigations
```
